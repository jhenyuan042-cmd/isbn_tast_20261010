A 方案：Google 搜尋 API 設定

A 方案使用 Google Programmable Search Engine 全網檢索，每日提供 100 次完全免費額度。金鑰僅儲存在您的瀏覽器本地，安全不外洩。

由 Google Cloud Console 建立之金鑰（需啟用 Custom Search API 及可選啟用 Books API）
於 Google 自訂搜尋引擎 (cse.google.com) 取得之「搜尋引擎 ID」，需開啟「搜尋整個網路」

2 分鐘快速取得教學：

  1. 前往 Google 自訂搜尋引擎 建立搜尋引擎，搜尋範圍選擇「搜尋整個網路」，複製 搜尋引擎 ID (cx)。
  2. 前往 Google Cloud API 憑證 啟用 Custom Search API 並取得 API Key。
